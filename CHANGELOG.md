# Changelog

## 1.0.0 · 2026-11-23

- Exact decimal classification, signed orders and bounded symbolic power handling.
- A monochrome visual scale of five mouths and three eyebrow positions, plus a dedicated zero expression.
- Sequential and Simultaneous standards with a common encoded result.
- Offline comparison demo with keyboard controls, text descriptions and reduced-motion support.
- Movable 15-position logarithmic scale with exact positive and negative offsets, a slider for A, and a shared reference window for B.
- Adjustable looping playback in both standards and stable slider positioning when expression descriptions wrap.
- Clearer starting values, a visual eyebrow key, and a compact comparison layout for phones.
- Selectable text, optional local Russian speech, and a space navigation example with separate Magnitude and Mission modes.
- Author-approved Russian and English names for all five faces and three eyebrow positions, shared by the visual, text and speech channels.
- Ten offline interface languages, Arabic RTL, language-matched local speech, and light, dark and system themes.
- Explicit Auto and Manual windows, sequential brow reveal, and certified decimal orders for large integer powers.
- Sequential playback at 0.5× on startup and a directly visible speed control on desktop.
- Mathemote project naming, attribution and provenance, separate Apache 2.0 and CC BY 4.0 scopes, and a publication and citation plan.
- Automated boundary tests, bilingual documentation, a volunteer protocol and release metadata.
- A standalone About page in all ten interface languages with three use cases and static face examples.
