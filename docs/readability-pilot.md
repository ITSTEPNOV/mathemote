# Пилотная проверка человекочитаемости

Цель пилота - выяснить, какие положения рта и бровей добровольцы различают, как быстро осваивают код и насколько удобно воспроизводят оба стандарта. Это разведочная проверка. Её результаты применимы к проверенным условиям и выборке.

## Подготовка

- Пригласите 6–10 добровольцев на 10–15 минут. Предупредите, что любой этап можно пропустить или прекратить.
- Используйте монохромные изображения одинакового размера. Для заданий на распознавание подготовьте карточки или обрезанные изображения, скрыв исходное число, подписи и шкалу. Для последовательной передачи используйте живой показ или локальную анимацию с закрытой областью ответа.
- Возьмите примеры из всех пяти групп и все три положения бровей. Включите пары на границе групп и пары из одного порядка. Для последних правильный ответ по одному лицу - «один порядок», даже если исходные числа различаются.
- Чередуйте порядок стандартов между добровольцами. Используйте сопоставимые, но разные значения в двух сериях: например, переходы `10^5 → 10^6` и `10^8 → 10^9`. В последовательной передаче выдерживайте пять секунд для B1.

## Задания

1. **До объяснения.** Перемешайте F0–F4 с одинаковыми нейтральными бровями. Попросите расставить их по возрастанию величины. Запишите порядок идентификаторов и неопределённые позиции. Это проверка предполагаемой интуитивной последовательности.
2. **Ознакомление.** Покажите шкалу на одну минуту. Объясните по одному примеру для B0, B1 и B2. Уберите шкалу перед заданиями.
3. **Сравнение.** Покажите четыре пары. Попросите выбрать лицо с большим порядком или указать равенство порядков. Включите пару с разными ртами, пару с одинаковым ртом и разными бровями, пару через границу групп и пару с одинаковым кодом.
4. **Оценка масштаба.** Покажите пять отдельных комбинаций. Попросите назвать приблизительный диапазон или порядок. Запишите оценку и ошибку в порядках, если ответ числовой. Повторите часть карточек в размере 32–40 CSS-пикселей, чтобы увидеть, какие детали теряются.
5. **Два стандарта.** Дайте по три примера для распознавания в каждом режиме, включая B1. Предложите воспроизвести две комбинации по желанию. Запишите ошибки, время от начала показа до ответа, предпочтение и удобство по шкале 1–5. Длительность нормативной паузы учитывайте при сравнении времени.
6. **Без цвета.** Попросите оценить понятность монохромного показа по шкале 1–5 и назвать формы, которые было трудно отличить. Запишите комбинации, оказавшиеся трудными для воспроизведения.

## Фиксация результатов

Одна анонимная строка на попытку. Случайный код сессии нужен только для связи заданий одного добровольца. Имена, контакты, демографические сведения, записи лица и голоса и свободные комментарии с идентифицирующими деталями не собираются.

```text
session_code,task,standard,stimulus,expected,response,correct,time_seconds,ease_1_5,note
```

Подведите итоги по заданиям. Для порядка гримас сохраните частоты перестановок, для распознавания - число правильных ответов и частые пары ошибок, для оценки масштаба - распределение абсолютной ошибки в порядках. Для сравнения стандартов укажите число попыток и пропусков, медианное время, предпочтения и оценки удобства. Проверьте, различают ли участники выражения «Стиснутые губы» (F2), «Нейтральный рот» (F1) и «Оскал» (F4). Зафиксируйте размер изображений, условия показа и порядок серий. Результаты добровольцев пока отсутствуют.
