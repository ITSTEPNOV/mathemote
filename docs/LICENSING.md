# Mathemote licensing

Mathemote is the software implementation and facial notation of Stepnov's Method. Igor Stepnov is credited for the original concept and methodology. Attribution for the implementation and other contributions is recorded separately in [AUTHORS.md](../AUTHORS.md) and [NOTICE](../NOTICE).

The software scope covers the original implementation code in `src/`, the application HTML and CSS, the examples, the tests and the supporting code in the project documentation. This includes the drawing and rendering code in `src/faces.js`. The [LICENSE](../LICENSE) file contains the unmodified official English license.
